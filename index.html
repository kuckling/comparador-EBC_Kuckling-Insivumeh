Cómo publicar esta aplicación en GitHub Pages

Para publicar esta plataforma de forma **100% gratuita y pública** con datos en vivo para la comunidad:

  1. Cree un repositorio público en GitHub llamado red-ebc-comparador.
  2. Guarde este código en un archivo llamado obligatoriamente index.html.
  3. Suba el archivo index.html a la rama principal (main).
  4. Vaya a **Settings** → **Pages** en su repositorio de GitHub.
  5. En **Source**, seleccione la rama main y guarde.
  6. En un par de minutos, su sitio estará en vivo en: https://tu-usuario.github.io/red-ebc-comparador/
